# Provider adapters (withheld)

Browser adapters for hosted video and image services (`generate_hailuo.js`, `generate_dreamina.js`, `gen_storyboard_hailuo.js`). Each drives the user's own logged-in browser on the user's own account, one job at a time, and downloads only the user's own generations. They are withheld. `make_video.js` shows where they plug in; `atlas_cloud.py` and `make_video_atlas.py` show the same stages through an official API.
